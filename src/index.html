What is THE HOLE?

A practitioner-first search engine that finds things people actually built. No ads. No tracking. No cookies. No SEO slop.

What is BLOOM?

BLOOM is THE HOLE's browser -- a desktop browser where the search engine is not a feature but the foundation. Every page you visit is analyzed by the slop shield: affiliate links are dimmed, low-quality content is flagged, and source tiers are shown for known domains. Reader mode strips pages to clean text with metadata. The address bar is the search bar.

How it works

THE HOLE crawls primary sources — arXiv, GitHub, Hacker News, Stack Overflow, PubMed, practitioner blogs, Lobsters, and IETF RFCs. Every document passes through a slop filter that detects listicles, affiliate spam, keyword stuffing, and LLM-generated content. Surviving documents are scored by a transparent ranking algorithm that rewards real practitioners who build real things.

Ranking is public

The ranking algorithm is fully open source. If knowing the algorithm lets you game it, the algorithm is bad. THE HOLE resists gaming because the optimal strategy is: write real content about things you actually built. The game theory is the alignment.

Source tiers

T1 Primary sources — arXiv, GitHub, PubMed, RFCs
T2 Practitioner sources — HN, SO, Lobsters, quality blogs
T3 Journalism — vetted tech reporting
T4 Other — lower confidence, deprioritized

Shortcuts

In the BLOOM address bar:
:gh query — search GitHub
:arxiv query — search arXiv
:hn query — search Hacker News
:so query — search Stack Overflow
! query — Google fallback
