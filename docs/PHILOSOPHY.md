# Philosophy

## Why THE HOLE exists

Most search engines have become advertising platforms that happen to show
some results. The incentives are misaligned: the search engine profits when
you click ads, not when you find what you need. The result is an arms race
between SEO operators and ranking algorithms, where practitioners -- the
people who actually build things -- lose.

THE HOLE is a practitioner-first search engine. It indexes primary sources:
research papers, code repositories, technical Q&A, practitioner blogs, and
internet standards. Every document passes through a slop filter that rejects
listicles, affiliate spam, keyword stuffing, and LLM-generated filler. What
remains is ranked by a transparent algorithm that rewards real work.

## Why BLOOM exists

A search engine that lives inside another browser is always a guest. The
browser's incentives (default search deals, sponsored tiles, data collection)
conflict with the search engine's job. BLOOM eliminates this conflict by
making the browser and the search engine the same thing.

In BLOOM, the address bar is the search bar. Every page you visit is analyzed
by the slop shield. Affiliate links are dimmed. Source tiers are shown for
known domains. Reader mode strips pages to clean text. There is no "default
search engine" setting because there is no separation between searching and
browsing.

The browser IS the search engine.

## Principles

**No ads.** THE HOLE shows zero advertisements. Revenue comes from optional
donations and grants, not from selling attention.

**No tracking.** No cookies, no fingerprinting, no analytics, no telemetry.
BLOOM stores all data locally. Nothing leaves your machine.

**No telemetry.** The browser does not phone home. There are no crash reports,
no usage statistics, no "anonymous" data collection. If you want to report a
bug, you do it manually on GitHub.

**Algorithm is public.** The full ranking algorithm is open source. If knowing
the algorithm lets you game it, the algorithm is bad. THE HOLE resists gaming
because the optimal strategy is: write real content about things you actually
built. The game theory is the alignment.

**Transparency over obscurity.** Security through obscurity is not security.
Ranking through obscurity is not ranking. Every decision THE HOLE makes is
auditable by anyone.

**Practitioners first.** The target user is someone who builds things and
needs to find other things people built. Not someone who needs to buy things
or be entertained.
