Features

Slop Shield

Every page is analyzed in real-time. Tracking scripts blocked. Affiliate links dimmed. LLM-generated content flagged. You see the web without the garbage.

Practitioner Search

THE HOLE indexes arXiv, GitHub, HN, Stack Overflow, PubMed, practitioner blogs, Lobsters, and RFCs. Results ranked by who actually builds things.

Reader Mode

Ctrl+R strips any page to clean text. System serif font, centered, no clutter. Code blocks preserved. Affiliate links removed.

Source Shortcuts

Type :gh rust parser for GitHub, :arxiv transformers for arXiv, :hn distributed for HN, :so python async for Stack Overflow.

Local-Only Data

Bookmarks, history, and settings stored in SQLite on your machine. No cloud sync. No account. No telemetry. The browser forgets you exist when you close it.

Transparent Algorithm

The ranking algorithm is fully public. If knowing it lets you game it, the algorithm is bad. The optimal strategy is: write real content about things you built.

Build from source

# Clone
git clone https://github.com/teslasolar/thehole.git
cd thehole

# Install Rust (if needed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Tauri CLI
cargo install tauri-cli --version "^2" --locked

# Linux: install system deps
sudo apt-get install libwebkit2gtk-4.1-dev libgtk-3-dev \
  librsvg2-dev patchelf libsoup-3.0-dev

# Build
cargo tauri build

# Or run in dev mode with hot reload
cargo tauri dev

# Android
cargo tauri android build

# iOS
cargo tauri ios build
