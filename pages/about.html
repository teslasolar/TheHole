About THE HOLE

THE HOLE is a practitioner-first search engine. It indexes primary technical sources and ranks them with a transparent, open-source algorithm that rewards people who build real things.

Why it exists

Google search is broken for technical queries. The first page is SEO-optimized listicles, affiliate content, and AI-generated filler. The actual answer — written by someone who built the thing — is buried on page 3, if it's indexed at all.

THE HOLE fixes this by only indexing primary sources and filtering everything else out.

What it indexes

T1 Primary sources — arXiv, GitHub, PubMed, IETF RFCs. The origin of knowledge.

T2 Practitioner sources — Hacker News, Stack Overflow, Lobsters, and 54+ curated practitioner blogs (Julia Evans, Dan Luu, Rachel Kroll, Drew DeVault, and more). Written by people who build things.

T3 Journalism — Vetted tech reporting. Rare, deprioritized unless it adds signal.

How ranking works

Every document gets a composite score from six signals:

  • Slop score (25%) — is the content clean?
  • Practitioner score (25%) — does the author build things?
  • Citation score (20%) — do other primary sources link to this?
  • Freshness (15%) — exponential decay, 180-day half-life
  • Depth (10%) — word count, code blocks, data, citations
  • Source tier (5%) — base score from the platform

The entire algorithm is public. This is deliberate.

If knowing the algorithm lets you game it, the algorithm is bad.

Anti-gaming

THE HOLE's ranking resists gaming structurally:

  • Practitioner score requires real GitHub commits over months/years
  • Citation score requires real inbound links from Tier 1 sources
  • Slop filter penalizes the exact things SEO gamers do
  • The optimal strategy for ranking well is: write real content about things you actually built
The game theory IS the alignment.

About BLOOM

BLOOM is THE HOLE as a standalone browser. Built with Tauri (Rust + system webview), it's ~4MB instead of Chrome's ~300MB. It doesn't ship Chromium. It doesn't track you. The address bar IS the search engine.

Every page you visit is analyzed by the slop shield. Tracking scripts are blocked. Affiliate links are dimmed. LLM-generated content is flagged. Reader mode strips pages to clean text.

Your bookmarks and history stay on your machine. There's no cloud sync, no account, no telemetry. The browser forgets you exist when you close it.
