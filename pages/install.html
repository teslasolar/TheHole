Install Guide

Linux

Debian / Ubuntu (.deb)

wget 'https://github.com/teslasolar/TheHole/releases/latest/download/THE%20HOLE%20BROWSER_0.1.3_amd64.deb'
sudo dpkg -i 'THE HOLE BROWSER_0.1.3_amd64.deb'

Fedora / RHEL (.rpm)

wget 'https://github.com/teslasolar/TheHole/releases/latest/download/THE%20HOLE%20BROWSER-0.1.3-1.x86_64.rpm'
sudo rpm -i 'THE HOLE BROWSER-0.1.3-1.x86_64.rpm'

Any distro (.AppImage)

wget 'https://github.com/teslasolar/TheHole/releases/latest/download/THE%20HOLE%20BROWSER_0.1.3_amd64.AppImage'
chmod +x 'THE HOLE BROWSER_0.1.3_amd64.AppImage'
./'THE HOLE BROWSER_0.1.3_amd64.AppImage'
Linux requires WebKitGTK 4.1. Most modern distros include it. If not: sudo apt install libwebkit2gtk-4.1-0

macOS

Apple Silicon (M1/M2/M3/M4)

curl -LO 'https://github.com/teslasolar/TheHole/releases/latest/download/THE%20HOLE%20BROWSER_0.1.3_aarch64.dmg'
open 'THE HOLE BROWSER_0.1.3_aarch64.dmg'
# Drag to Applications

Intel

curl -LO 'https://github.com/teslasolar/TheHole/releases/latest/download/THE%20HOLE%20BROWSER_0.1.3_x64.dmg'
open 'THE HOLE BROWSER_0.1.3_x64.dmg'
macOS may show "unidentified developer" warning. Right-click the app and select Open, or: xattr -cr /Applications/THE\ HOLE\ BROWSER.app

Windows

Installer (.exe)

Download THE HOLE BROWSER_0.1.3_x64-setup.exe and run it.

MSI (silent install)

msiexec /i "THE HOLE BROWSER_0.1.3_x64_en-US.msi" /quiet
Windows requires WebView2 runtime. Windows 10 (2004+) and Windows 11 include it. If missing, the installer will prompt you to install it.

Android

Download the .apk file and install it. You may need to enable "Install from unknown sources" in Settings.

Requires Android 7.0 (API 24) or later.

iOS

iOS builds are coming soon via TestFlight. Apple's App Store review process takes time. In the meantime, you can use THE HOLE search engine directly in Safari at the web frontend.

Build from source

For any platform:

# Prerequisites: Rust, Tauri CLI
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
cargo install tauri-cli --version "^2" --locked

# Clone and build
git clone https://github.com/teslasolar/TheHole.git
cd TheHole
cargo tauri build

For Android and iOS mobile builds:

# Android (requires Android SDK + NDK)
cargo tauri android build

# iOS (requires Xcode, macOS only)
cargo tauri ios build

Search engine only (no browser)

THE HOLE search works in any browser with zero install:

git clone https://github.com/teslasolar/TheHole.git
cd TheHole/frontend
python3 -m http.server 8000
# Open http://localhost:8000

To build the full index from crawled sources:

pip install -r requirements.txt
python scripts/build_index.py
